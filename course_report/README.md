# Course Report

This folder is the expanded UCSD course-project deliverable. It is deliberately
more explanatory than the 4-page CCAI-style paper in `paper/`.

Recommended use:

1. Start from `report.md`.
2. Pull figures from `figures/`, especially `fig1_domain_map.pdf`,
   `fig3_pcmci_graphs.pdf`, `fig5_ace_comparison.pdf`, and
   `fig7_primary_holdout_summary.pdf`.
3. Use the machine-readable diagnostics in `results/` for tables:
   `baseline_logistic.json`, `backbone_sensitivity.json`,
   `projection_lag_sensitivity.json`, and `holdout_interval_audit.json`.
