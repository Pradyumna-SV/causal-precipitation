# Analysis plan: strong-effects search (gates, pre-spec, multiplicity)

This document fixes **what counts as evidence** before iterative specification search. It pairs with [`config/analysis_registry.yaml`](../config/analysis_registry.yaml) and [`results/robustness_report.json`](../results/robustness_report.json) (generated by `scripts/robustness_bundle.py`).

## Gates A–D (all required for a “main text” causal claim)

| Gate | Requirement | Evidence |
|------|-------------|----------|
| **A. Estimand clarity** | One sentence: treatment, outcome, contrast, calendar window, population (regions / pooled), and season mask—must match [`scripts/04_causal_inference.py`](../scripts/04_causal_inference.py) + active config. | `manuscript_brief.json` → `estimand`; config YAML |
| **B. Statistical strength** | For the **pre-specified primary** scale (risk difference): **95% CI excludes zero**; **IPW** and **DR** same direction and intervals not in blatant conflict (overlap or same sign). | `ace_*.json` / `ace_all_regions.json` |
| **C. Identification stress** | **≥ 2** checks pass among: overlap / ESS-style weight diagnostics, placebo / label perturbation, alternate season window, alternate Niño threshold (if applicable), lag / falsification described in robustness report. | `robustness_report.json` → `checks` |
| **D. Multiplicity hygiene** | Either (i) **single primary** estimand with **temporal holdout confirmation** (fit nuisance models on an early window, report ACE + CI on a disjoint later window), or (ii) a **closed list** of exploratory presets (this repo: `config/presets/`) with an explicit **Benjamini–Hochberg FDR** or hierarchy rule documented here and in `manuscript_brief.json`. | `results/holdout_validation.json` + this file + registry |

Exploratory analyses **must not** be promoted to “primary” in prose without satisfying (i) or (ii).

## Pre-specified primary (Phase 0)

- **Config preset:** `primary` → [`config/presets/primary.yaml`](../config/presets/primary.yaml) (merged after `base` + `local` via `CAUSAL_PRESET`).
- **Treatment / outcome:** Described in `manuscript_brief.json` under `estimand` (binary warm SST vs not on regional `tp_extreme` unless the registry is updated).
- **Gate B region:** `pacific_northwest` by default (see registry)—change only by editing [`config/analysis_registry.yaml`](../config/analysis_registry.yaml) **before** looking at results intended for claims.

Changing the gate-B region after viewing results invalidates gate D unless declared exploratory and corrected.

## Temporal holdout (recommended for gate D)

1. **Train window:** default `1979-01`–`1999-12` — fit propensity / DR nuisance models.
2. **Evaluation window:** default `2000-01`–`2023-12` — report ACE + bootstrap CI on evaluation rows only, with nuisances fixed from train.
3. **Artifact:** [`scripts/holdout_validation.py`](../scripts/holdout_validation.py) writes `results/holdout_validation.json` for the frozen primary gate-B claim.

For a strong causal-climate claim, require `strict_statistical_replication: true` (IPW and DR held-out CIs exclude zero in the full-sample direction). `directional_replication: true` is useful supporting evidence but should not be sold as confirmation by itself.

## Exploratory grid (closed list)

Candidates are YAML presets under [`config/presets/`](../config/presets/). **Order of priority** (per strong-effects search plan):

1. Align estimand with ENSO / SST (thresholds, alternative Niño contrasts—already partially in ACE JSON).
2. Outcome / extreme definition (percentile changes **require** re-running preprocess → discovery → inference).
3. **Pooled western US** — [`scripts/pooled_ace.py`](../scripts/pooled_ace.py) writes `results/pooled_ace.json` (stacked regions, cluster bootstrap on time).
4. Overlap / trimming — preset `overlap_trim` + `inference.ipw_ps_trim_quantiles`.
5. Season mask — `full_year`, `season_ndjf` presets (full-year and discovery changes require re-running [`scripts/03_causal_discovery.py`](../scripts/03_causal_discovery.py)).

Run the grid without overwriting release artifacts:

```bash
python scripts/run_search_grid.py
```

Or a single variant:

```bash
CAUSAL_PRESET=full_year make preprocess discovery inference
```

(Use `paths.results` in the preset so outputs stay under `results/grid/...`.)

## Multiplicity: Benjamini–Hochberg (exploratory presets)

When reporting **exploratory** risk-difference p-values or interval endpoints across **M** presets for the **same** outcome family:

1. Extract one z-stat (or edge of CI) per preset **defined in the registry list**.
2. Apply BH-FDR at \(q = 0.10\) (or pre-specify stricter \(q\)) on the **closed** list only—no adding presets after seeing results without restarting the multiplicity budget.

The **primary** preset is excluded from FDR if it stands alone as main claim; secondary claims must be FDR-adjusted or holdout-confirmed.

## What success does *not* mean

- Significance on a **tortured** estimand added after seeing data without holdout or FDR.
- Treating PCMCI/VAR graphs as the identification source of truth (they are exploratory inputs to the lag-0 projection).
